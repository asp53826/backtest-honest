
  Best-in-sample Sharpe climbs with the number of variants tried and
  tracks the theoretical maximum of that many null draws. Nothing was
  learned; the search space grew. Deflated Sharpe declines to call any
  of it skill, which on this data is the only correct answer.

=== power: how large must a real edge be to survive the correction? ===

  A correction that rejects everything is not a correction, so the same
  500-variant search is run on markets with genuine AR(1) momentum of
  increasing strength. phi = 0 is the null and must be rejected.

     bars    phi  best Sharpe  deflated p   verdict
  -------------------------------------------------
    2,000   0.00        0.985       0.391    search
    2,000   0.10        1.083       0.499    search
    2,000   0.20        1.266       0.695    search
    2,000   0.35        2.207       0.999     SKILL
    5,000   0.00        0.525       0.238    search
    5,000   0.10        0.603       0.356    search
    5,000   0.20        0.727       0.574    search
    5,000   0.35        1.375       0.999     SKILL
   20,000   0.00        0.220       0.137    search
   20,000   0.10        0.289       0.317    search
   20,000   0.20        0.505       0.925    search
   20,000   0.35        1.234       1.000     SKILL

  It discriminates: phi = 0.35 is accepted at every sample size and the
  null is rejected at every sample size. But the bar is high. A phi of
  0.10 — a real, exploitable edge — is never accepted, not even with
  20,000 bars, and phi = 0.20 only reaches 0.925 there.

  That is the cost, stated plainly: trading false positives for false
  negatives. After a 500-variant search, a modest genuine edge is
  indistinguishable from having looked hard enough — and no amount of
  additional data fixes it, because searching 500 variants raises the
  bar by more than the extra data lowers it.

=== false discovery rate of an uncorrected backtest ===

  200 independent random-walk markets. Each gets a 500-variant search.
  A naive backtest calls it a discovery when the best Sharpe beats 1.0.

  method                              discoveries     rate
  --------------------------------------------------------
  naive: best Sharpe > 1.0                     15    7.5%
  deflated Sharpe p > 0.95                      0    0.0%

  True discoveries available in this data: 0. Every naive hit is a
  false positive produced entirely by searching.
